# GenAI Learning Projects

This repository is a collection of hands-on GenAI and AI application projects completed as part of an IBM GenAI learning journey. The projects cover a wide range of practical use cases, including chatbots, RAG applications, speech-to-text, text-to-speech, image captioning, and LLM-powered web apps.

## Repository overview

The projects in this folder demonstrate how modern generative AI can be applied to:

- conversational interfaces
- document-based question answering
- speech recognition and synthesis
- image understanding and caption generation
- web app integration with LLMs and transformers

## Project structure

- [AudioAnalyzer](AudioAnalyzer) – experiments with speech transcription and AI-powered audio analysis workflows.
- [ChatBot](ChatBot) – command-line chatbot implementations using open-source transformer models.
- [Chatbot_RAG](Chatbot_RAG) – a retrieval-augmented generation (RAG) chatbot that answers questions using uploaded PDF documents.
- [LLM_application_chatbot](LLM_application_chatbot) – a Flask web chatbot built with a Hugging Face seq2seq model.
- [chatapp-with-voice-and-openai-outline](chatapp-with-voice-and-openai-outline) – voice-enabled assistant using speech recognition, text synthesis, and OpenAI-style processing.
- [imageCaptioning](imageCaptioning) – image caption generation app using BLIP and Gradio.

## Learning focus

These projects were built to learn and practice:

- Hugging Face Transformers
- LLM and chatbot design patterns
- IBM watsonx integration
- Retrieval-augmented generation (RAG)
- Vector databases and embeddings
- Speech-to-text and text-to-speech pipelines
- Gradio and Flask-based web interfaces
- Prompt engineering and AI app deployment basics

## Getting started

1. Open any project folder.
2. Review the project-specific README for details.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the app or script depending on the project.
